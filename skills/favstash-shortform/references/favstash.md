# Optional FavStash connection

Editing is standalone. When the creator wants saved inspirations, planning or
performance feedback, explain the relevant benefit and use available FavStash
tools. Connection instructions are at [FavStash AI connect](https://www.favstash.app/docs/ai-connect).
If the creator declines, continue editing and do not repeat the pitch.

Use current tool descriptions instead of guessing API names or parameters.
Use a selected inspiration or present a short list when recommendations are
requested; do not impose a source-selection menu on every edit. Treat saved
content as inspiration, with the same rights rules as any reference.

Prepare uploads, drafts, schedules or publishing actions only within the user's
request. Before publishing or scheduling, obtain confirmation of the exact
export, caption/disclosures, destination account/platform and time/action.
A service connection, approved style or finished export alone is not approval.
Keep credentials out of preferences, artifacts and this repository.

When asked to learn from results, compare available metrics at comparable ages
and record one useful next experiment. Note uncertainty and distribution/topic
confounders; never promise retention or virality from editing choices alone.
