# Talking-Head Short

Preserve the speaker's humanity and meaning. The goal is clarity and momentum, not robotic removal of every pause.

## Workflow

1. Read the shared [short-form rules](../favstash-shortform/references/shortform-rules.md) and [`references/recut-guide.md`](references/recut-guide.md).
2. Create a dated run with style `talking-head-short`; record the source footage as `owned` or the appropriate user-confirmed status.
3. Transcribe with timestamps. Read the full local context before selecting a hook so a sentence is not made misleading.
4. Make a paper edit using transcript ranges. Remove repetition, false starts, and dead setup; retain meaningful breaths, reactions, and transitions.
5. Build a clean audio edit first. Cover unavoidable jump cuts only where B-roll, a crop change, or a graphic adds meaning.
6. Reframe face/eyes for 9:16 and check movement throughout, not only at the first frame.
7. Add `$shortform-captions`; add proof overlays, lower thirds, or `$shortform-sound-design` selectively.
8. Review the uncaptioned meaning, caption accuracy, lip/audio sync, continuity, and phone framing with `$shortform-review`.

Do not synthesize new words in the speaker's voice or alter a testimonial's meaning without explicit instruction and appropriate disclosure.
