# Split-Screen Short

Give each pane a reason to exist. If viewers must choose between two unrelated stories, use sequential shots instead.

## Workflow

1. Read the shared [short-form rules](../favstash-shortform/references/shortform-rules.md) and [`references/layout-guide.md`](references/layout-guide.md).
2. Create a dated run with style `split-screen-short` and ledger both sources.
3. Write each pane's role in the plan: `speaker/context`, `proof/demo`, `reaction/source`, `before/after`, or another explicit relationship.
4. Choose horizontal, vertical, inset, or dynamic handoff based on the content's natural geometry and priority—not a fixed template.
5. Align the important moments. Crop each source independently, preserving faces, product controls, and readable evidence.
6. Reduce competing motion and duplicate text. Let one pane lead at a time through scale, contrast, blur, dimming, or a temporary full-frame takeover.
7. Mix audio around one intelligible leader. If both sources speak, sequence or duck them; avoid simultaneous competing dialogue.
8. Review at phone size and finish with `$shortform-review`.

For reaction/source media obtained from a URL, use the shared [reference rights workflow](../favstash-shortform/references/rights-and-reference-media.md). Analysis access does not permit publishing that source pane.
