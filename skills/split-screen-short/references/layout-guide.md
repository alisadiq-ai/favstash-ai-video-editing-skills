# Split-screen layout guide

## Choose the relationship first

- **Speaker + proof/demo:** prioritize the demo when interaction detail matters; prioritize the face when trust/emotion matters.
- **Reaction + source:** keep the source large enough to understand and confirm publishing rights for both.
- **Before + after:** match crop, scale, timing, and labels so the comparison is honest.
- **Claim + data:** the evidence pane should show a legible number or pattern, not a tiny screenshot.

## Layout options

- **Top/bottom:** natural for two horizontal clips in a vertical canvas. Faces often work above and screen/action below, but test caption collisions.
- **Left/right:** useful for symmetric comparisons; narrow panes can damage face and phone-screen legibility.
- **Inset/PiP:** best when one source is continuous context and the other is primary.
- **Dynamic handoff:** start split, then expand the source that needs attention. Use sparingly and keep directional continuity.

Start near a balanced division, then weight the pane carrying the current beat. Dividers can be a small gap, a brand-color rule, or no visible line if contrast is clear.

## Failure modes

- two moving panes plus animated captions competing at once;
- essential UI/details rendered too small;
- mirrored or mismatched before/after framing;
- publishing a downloaded reaction/source clip under `analysis-only`;
- keeping split screen for the entire edit when full-frame focus would explain a key moment better.
