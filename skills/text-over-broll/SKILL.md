# Text Over B-Roll

The writing and footage must strengthen each other. Do not place generic stock clips behind a paragraph and call it an edit.

## Build the edit

1. Read the shared [short-form rules](../favstash-shortform/references/shortform-rules.md) and [`references/style-guide.md`](references/style-guide.md).
2. Create a dated run with style `text-over-broll`.
3. Choose `fresh`, `stash-selected`, or `stash-recommended`. If a URL reference controls the visual grammar, use the shared [rights-aware analysis workflow](../favstash-shortform/references/rights-and-reference-media.md).
4. Distill the idea to one tension and payoff. Write two or three hook variants before polishing.
5. Search `broll-index.v1.json` by semantic role—setting, action, energy, movement, and metaphor—not filename alone. Log selected assets and rights.
6. Make a paper edit: each text beat gets a visual purpose and enough reading time. Remove any shot that does not add mood, evidence, contrast, or continuity.
7. Compose in HyperFrames. Build hierarchy through timing, line breaks, position, and restrained emphasis; avoid a different effect for every sentence.
8. Add music/SFX only when they improve the emotional curve. Render at least one phone-size preview.
9. Finish with `$shortform-review`.

If B-roll is insufficient, show the specific missing roles and offer a version using fewer stronger shots, abstract brand motion, or creator-approved sourcing. Do not silently pull unlicensed social footage.

Deliver the selected export plus the hook, text sequence, B-roll choices, and creative hypothesis.
