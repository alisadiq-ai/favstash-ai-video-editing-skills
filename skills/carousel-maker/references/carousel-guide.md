# Carousel guide

## Narrative shapes

- **Promise → steps → payoff:** practical teaching.
- **Observation → evidence → reframe:** thought leadership.
- **Before → decisions → after → lesson:** case study.
- **Myth → why it persists → correction → application:** contrarian education.
- **Moment → tension → turn → reflection:** personal story.

A common sequence has 5–10 slides, but the right count is the shortest sequence that completes the idea and fits the destination's current limits.

## Slide jobs

- Cover: a specific honest promise/tension, not an unlabeled topic.
- Setup: the minimum context needed to care.
- Body: one main idea per slide; use diagrams, examples, comparisons, or evidence where possible.
- Transition: occasional bridge or reset when the structure changes.
- Payoff: synthesize rather than repeat.
- Close: useful next action or memorable final line; a CTA is optional.

## Design system

Use creator preferences for type, colors, voice, and logo behavior. Define CSS variables and reusable slide components so future carousels can evolve consistently. Maintain strong outer margins, clear baseline rhythm, and one visual anchor per slide.

Treat 54–88 px as a starting range for body display text on 1080-wide slides and 80–140 px for covers, then test real copy. Reduce copy before shrinking it into unreadability.

## Continuity

Repeat a position, number, rule, motif, or image edge across slides so swiping feels intentional. Vary composition enough to avoid monotony but keep the same design language. Avoid putting a progress indicator where platform UI covers it.

## Delivery

Export lossless PNGs or platform-appropriate high-quality JPEGs in numerical order. Include a contact sheet, alt text, caption, asset attribution, canvas/format, and editable source. Verify no text or image is clipped after export.
